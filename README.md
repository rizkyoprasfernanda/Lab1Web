5.  Memformat Teks

Pada tahap ini dilakukan pemformatan teks menggunakan beberapa tag HTML.

Penjelasan Tag yang Digunakan

- `<b>` digunakan untuk membuat teks menjadi tebal, biasanya digunakan untuk menonjolkan teks tanpa memberikan makna atau penekanan khusus secara semantik.
- `<i>` digunakan untuk membuat teks menjadi miring, misalnya untuk menandai istilah atau kata tertentu.
- `<strong>` digunakan untuk memberikan penekanan penting pada suatu teks. Secara visual biasanya ditampilkan dalam bentuk tebal.
- `<em>` digunakan untuk memberikan penekanan atau penegasan pada teks. Secara visual biasanya ditampilkan dalam bentuk miring.
- `<mark>` digunakan untuk menyorot atau memberi tanda (highlight) pada teks tertentu agar lebih mudah diperhatikan.
- `<small>` digunakan untuk membuat teks berukuran lebih kecil dibandingkan teks normal, biasanya digunakan untuk informasi tambahan atau keterangan.
- `<del>` digunakan untuk menunjukkan teks yang dihapus atau tidak berlaku lagi. Browser biasanya menampilkan teks tersebut dengan garis coret.
- `<ins>` digunakan untuk menunjukkan teks yang ditambahkan atau dimasukkan ke dalam suatu dokumen. Browser biasanya menampilkan teks tersebut dengan garis bawah.
- `<sub>` digunakan untuk membuat teks subscript, yaitu teks yang ditampilkan sedikit lebih rendah dari posisi teks normal. Contohnya pada rumus kimia H<sub>2</sub>O.
- `<sup>` digunakan untuk membuat teks superscript, yaitu teks yang ditampilkan sedikit lebih tinggi dari posisi teks normal. Contohnya pada perpangkatan x<sup>2</sup>.
